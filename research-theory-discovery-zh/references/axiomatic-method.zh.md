# 公理化方法：逆向上升与正向下降

本文是 `SKILL.zh.md` 第一至第六节的展开，提供步骤细节、判据与例子。

## 1. 为什么用公理体系，而不是一句"第一性原理"

"第一性原理"只是一种态度；公理体系是一条有规则的生产线：哪些东西不加证明地接受，其余每一样都必须从它们推出来。它带来三件事：

- **可审计**：每个机制都能追溯到它依赖的公理。偷偷引入的假设会在 Lean 里暴露。
- **可判错**：预言失败时，能判断问题出在算法、扩张公理、推导，还是一般公理。
- **可迁移**：一般公理对所有对象成立。改变扩张公理或参数，同一套推导就能用到新对象上。

## 2. 两个历史例子

### 欧几里得到希尔伯特：隐藏假设会被找出来

欧几里得用 5 条公设推出 465 条命题。平行公设无法由前 4 条推出，换掉它就得到非欧几何，这正是"独立性反例"的原型。

1899 年，希尔伯特发现欧几里得的证明里偷用了没写下的假设，例如"两圆相交"、点在线段之间的次序，于是把它们补成明文公理。Lean 在今天承担的就是希尔伯特的角色。

### 牛顿：归纳上升、演绎下降、按层判错

- **上升**：第谷的观测，归纳出开普勒三定律（相当于扩张公理），再归纳出牛顿三定律加万有引力（一般公理加扩张公理）。
- **下降**：由牛顿公理演绎出开普勒定律，进一步预言新现象。
- **判错**：
  - 天王星异常，问题在"漏了天体"，属于扩张公理与数据层，于是找到了海王星；
  - 水星近日点异常，补"火神星"失败，最后改一般公理，得到相对论。

## 3. 逆向上升的判据

### 3.1 什么时候把一条规律升为扩张公理

- 有数据来源，并写清是哪份数据、哪个版本；
- 有留出检验，用的是未参与拟合的数据或对象；
- 写明失效范围，即在哪些条件下不适用。

缺任何一项，就是假设 H，不得进入定理链。

### 3.2 怎样从扩张公理走到一般公理

逐条问：

1. 这条规律是哪个更普遍约束的特例？
2. 两条规律能否由同一个约束推出？
3. 一个原始概念（如"能量"）能否由对称性推出？可以就消去它。随机过程里有 Baez–Fong 的诺特定理：一个量与生成元对易，等价于它的平均值和二阶矩对一切初态守恒；由时间反演对称和 Kolmogorov 判据，可以推出能量函数存在。
4. 一条约束是否其实是另一条的边界条件？例如"开放"是守恒律的边界条件，外部驱动就是打破时间平移对称。

### 3.3 独立性与一致性

- **独立性**：为每条公理构造"违反它、满足其余"的模型。例如"守恒、局部、有限"都满足的单向三元环 A→B→C→A，说明"无永动"不能由守恒推出，需要时间反演对称。
- **一致性**：构造一个满足全部公理的模型，或者指出一个现实中存在的系统。

### 3.4 区分定义、目标定理与公理

把研究目标的定义按句拆开：

- 描述**前提**的句子（如"有限资源、开放、置身无限信息流"）归入公理；
- 描述**要出现的性质**的句子（如"自发形成目的、形成世界模型"）写成主定理或存在性猜想，并拆成若干目标定理。

一个弱推导的例子是幸存者论证：在无限流中，不维持自身的结构会衰减，长期可观察到的只剩维持自身的系统。

### 3.5 参数

数值（压缩比、阈值、温度）是参数。参数取值可以用生物或工程数据做参照，例如基因组与接线信息量之比：果蝇约 0.3–5，人类约 1e-6–1e-7。但参数本身不进入公理，修改它也不触发判错。

## 4. 正向下降的判据

- **推导**：定理陈述里要写出依赖的条款。Lean 证明用"Lean 已证"；未形式化的写"纸面"。
- **算法**：
  - 参考实现在 Lean 中写成可计算定义，并证明关键性质；
  - 生产实现（Python、CUDA 等）与参考实现在共享测试向量上对拍；
  - 浮点与精确算术的差距单列；
  - 资源约束（内存、能耗、设备）属于目标契约，算法必须服从。
- **检验**：事前登记预测，设计关键实验，封住假胜利。结果作为新现象进入下一轮上升。

## 5. 判错顺序（自下而上）

| 步 | 层 | 典型检查 |
|---|---|---|
| 1 | 算法 | 与 Lean 参考实现对拍；步长收敛；实现是否真的实现了定理对象 |
| 2 | 扩张公理 | 换一条已登记的扩张公理，能否解释留出数据；是否超出失效范围 |
| 3 | 推导 | 有无未声明前提；Lean 审计是否通过 |
| 4 | 一般公理 | 先证明现象在现有公理下不可能（不可能定理），才修改公理 |

## 6. Lean 的组织方式

```lean
/-- 语言：不含关于研究对象的断言。 -/
structure JumpProcess (S : Type*) where
  rate : S → S → ℝ
  rate_nonneg : ∀ x y, 0 ≤ rate x y

/-- 公理条款写成谓词，不用 `axiom`。 -/
def Conserved (P : JumpProcess S) (Q : S → ℝ) : Prop :=
  ∀ x y, 0 < P.rate x y → Q x = Q y

/-- 定理的类型列出它用了哪些条款。 -/
theorem noether [Fintype S] (P : JumpProcess S) (Q : S → ℝ) :
    ((∀ x, P.gen Q x = 0) ∧ (∀ x, P.gen (fun s => Q s ^ 2) x = 0)) ↔ P.Conserved Q := …
```

## 7. 工作实例：构形生成脑（CGB）

一个研究"大脑如何由规则生成"的项目，用本方法得到以下结果：

- **上升**：
  - 从真实连接组归纳出扩张公理：相遇几何、低秩有向身份码、突起寿命的双时标；
  - 由此上升到三原则六条款：有限（状态有代价、作用要接触）、对称（守恒、时间反演、空间均匀）、对称破缺（边界、身份与位置、历史）。
- **合并**：
  - "有限容量、有限速率"由守恒加"没有免费状态"推出；
  - "无永动"由时间反演对称推出；
  - "开放"并入边界；
  - "能量"由可逆性推出；
  - "不能用全局反传"由"无限流加有限载体"推出，即"只能在线学习"定理。
- **Lean**：诺特对应、能量存在、单向环不可逆（P2b 的独立性反例）均已证明，审计通过。
- **定义拆分**："无限流生命体"的前提归入公理，"自发形成目的、世界模型、操作闭合"写成主定理。
- **判错**：一个由 30 多个手设常数构成的物理核，常数没有数据来源，被判为假设 H 并归档。它的"功能为零"的根因是没有按用途选择结构，不是参数没调好。
