## 研究树节点

### 可视化 JSON 输入

```json
{
  "title": "Research Tree",
  "nodes": [
    {
      "id": "N001",
      "parent": null,
      "title": "Initial hypothesis",
      "status": "active",
      "time": "2026-07-17 / commit abc123",
      "motivation": "为什么有这个节点",
      "action": "做了什么或测试了什么",
      "conclusion": "得到了什么结论",
      "issues": ["未解决问题"],
      "invalidation": "什么会让这个节点失效"
    }
  ]
}
```

渲染命令：

```bash
python scripts/render_research_tree.py tree.json tree.html
```
